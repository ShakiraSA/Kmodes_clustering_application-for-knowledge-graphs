<h2>Background</h2>
<p style="text-align: justify;">
Yōyaku annotates institutional PDF documents by extracting keywords and key phrases using Large Language Models (LLMs), leveraging Python libraries such as spaCy, RAKE and KeyBERT. This is accomplished by a back-end pipeline that initiates annotation based on responses submitted through a Google Form. Yōyaku supports multiple languages and was developed as part of a personal project. For security reasons, a static version is displayed. The prototype and its associated scripts are released under the Creative Commons Attribution-NonCommercial 4.0 International (CC BY-NC 4.0) license.
</p>
